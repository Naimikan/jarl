# AnchoredElement

## Basic usage

<PreviewBox>
  <AnchoredElement content="Anchored content">
    <span>Hover me</span>
  </AnchoredElement>
</PreviewBox>

```tsx
<AnchoredElement content="Anchored content">
  <span>Hover me</span>
```
